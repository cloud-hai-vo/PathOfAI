Key Findings

Chaos is MAGENTA (#d02090) — NOT purple (#9955dd). We had this wrong.
Fire is DARK RED (#960000) — NOT bright red (#cf3c18). Used as background tint.
Cold is STEEL BLUE (#366492) — We had #3674c2 which was close.
Default text is #7f7f7f — PoE uses this exact grey for muted text.
Stat values are pure WHITE — PoE shows numbers in #ffffff.
Explicit mods are BLUE (#8888ff) — The augmented/modifier color.
Crafted mods are LIGHT BLUE (#b8daf2) — Distinct from regular mods.
Success/Quest green is #4ae63a — Brighter than we had.
Tooltip bg is near-black (#111) — NOT brown/warm. PoE tooltips are very dark.
